## LinkedIn Post (Long Form)

I just open-sourced **Companies House Explorer**.

It is an interactive graph app for exploring UK company networks from Companies House data. You can search companies or officers, expand links, and visually inspect relationships between officers, PSCs, and companies.

I built this with **React + TypeScript + D3**, and added a server-side API proxy so the Companies House key stays out of client code.

What it does today:
- Graph-based relationship exploration
- Officer and company search
- Expandable network paths (company -> officer -> company)
- Basic shell-risk style signals and shared-officer overlays

What I would love feedback/contributions on:
- Better graph layout and performance for larger networks
- Additional analysis panels and scoring models
- UX polish and accessibility
- Export/report workflows

## GitHub Release Description

## Companies House Explorer - Open Source Launch

Initial public release of an interactive graph explorer for UK Companies House data.

### Highlights
- Company and officer search
- Graph exploration with expandable relationships
- Side-panel inspection for selected entities
- Relationship overlays and risk-oriented network cues
- Server-side API proxy pattern for key protection

### Getting Started
1. `npm install`
2. `cp .env.example .env.local`
3. Set `COMPANIES_HOUSE_API_KEY`
4. `npm run dev`

Contributions and feedback are welcome.

### Intro Draft

I built Companies House Explorer to make company relationship analysis more visual and less manual.  
Instead of jumping across multiple pages and raw lists, this app maps entities into an interactive graph where you can expand officers, companies, and ownership links step by step.

The project uses React + TypeScript for the UI, D3 for graph rendering, and server-side API proxy routes for secure Companies House access. In this post I will walk through the architecture, the graph-expansion model, and the areas where contributors can help improve the project.
