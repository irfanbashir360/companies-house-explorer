# Screenshot Checklist

Use this checklist to capture consistent visuals for the README and social launch posts.

## Core Product Shots

- [ ] Hero graph view after searching a company
- [ ] Officer search results dropdown
- [ ] Expanded network showing company-officer-company chain
- [ ] Info panel open on a selected company node
- [ ] Analysis panel with risk indicators visible
- [ ] Relationship overlay (shared officers) visible

## Quality Guidelines

- [ ] Browser zoom set to 100%
- [ ] Keep consistent viewport size across shots
- [ ] Avoid personal data in screenshots
- [ ] Remove API keys or sensitive values from dev tools
- [ ] Prefer PNG format for docs/social reuse
